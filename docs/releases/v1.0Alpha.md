Cineol-X 224 **1.0Alpha** for **macOS Universal** and **Windows x64**.
This is a GitHub prerelease; numeric plugin and bundle version: **1.0.0**.

### SPACE and converter-filter DIRT

- SPACE continuously slows each algorithm's DSP clock from its nominal rate
  to exactly half. Delays, modulation and controller time stretch together.
  The display shows DSP kHz, including 20.48–10.24 kHz for the original 224.
- DIRT now opens converter filter bandwidths up to full bypass instead of
  blending filtered and digital paths. Quantization, DAC holds and internal
  algorithm filters remain. At full bypass the output DC blocker is removed,
  so a small DC residual can remain.
- Settings includes **Analog filters follow DSP rate**. On scales converter
  filter frequencies with SPACE; off (default) keeps their physical frequencies
  fixed. DIRT opens the filters in either setting.

**Sound compatibility:** old sessions and presets with nonzero DIRT intentionally
sound different. Normal latency is now fixed across SPACE at 256 frames at
48 kHz, 398 at 44.1 kHz and 688 at 96 kHz, including host-rate conversion.
Low latency mode retains direct dry monitoring. Nominal-clock transport changes
converter phase relative to the signal/cold-start boundary; complete renders
are not claimed bit-identical to 0.99B. Keep previous binaries and session copies
if you need the exact earlier behavior.

### Four outputs in supporting hosts

The plugin has one mono/stereo input bus, Front stereo output (channels 1–2),
and an optional Rear stereo output (channels 3–4). Enable Rear in a host that
supports auxiliary effect outputs, then route 3–4 to a separate stereo track.
For example, REAPER/VST3 provides multichannel track/output routing. Each of
the four outputs independently selects an A/B/C/D engine output. Rear is wet
only at the Mix amount; dry input remains in Front.

**Logic Pro limitation:** Logic does not expose an additional Aux output from
an AU audio effect in the Audio FX slot. This release therefore remains stereo
in Logic. No Quad/surround or instrument/Side Chain variant is included.
The extra buses are plugin outputs, not automatically created physical hardware
outputs. Availability of independent signals also depends on the algorithm.

### Editor

- Six page-bound faders, Input/Mix, then SPACE/DIRT, with group separators.
- A wider display, evenly aligned global/status columns, balanced top/bottom
  padding and visible space above the fader rails.
- Plain bold controller text, captions enlarged by 12.5%, dark glass without
  a halo, and matte black worn fader caps and quick-preset keys.
- Help immediately beside Settings, retained in compact mode.
- Default 1104 x 696 full editor and 1104 x 252 compact editor, with resizing.

### Installation and migration

- **macOS Universal:** AUv2, VST3 and Standalone for Apple Silicon and Intel,
  macOS 11 or later. AU: `~/Library/Audio/Plug-Ins/Components/`; VST3:
  `~/Library/Audio/Plug-Ins/VST3/`; optional app: Applications. Bundles are
  ad-hoc signed and not notarized; see the archive's `INSTALL.txt`.
- **Windows x64:** VST3 and Standalone. Install the entire `.vst3` folder in
  `C:\Program Files\Common Files\VST3\`.

Restart or rescan the host after installation. Existing plugin identifiers,
parameter IDs and old host indices remain stable. New controls are appended.
Preset schema 5 accepts schemas 1–4 with defaults for the added controls;
new presets are intended for 1.0Alpha. Original-224 and XL version-5 caches
remain compatible. Re-import the complete XL v8.21 set only when upgrading
from an older XL prepared cache.

Archives contain documentation, installation instructions and build provenance.
SHA-256 checksums accompany both downloads. ROMs, prepared banks, captures and
private recordings are excluded. Supply your own original 224 v4.4 ROM1–ROM5,
and the complete 224XL v8.21 eleven-chip set for the optional XL preview.

### Validation and current limits

Local validation of the assembled feature change passed the full dual-bank
regression, preset/session migration, all-page UI/help checks and 108 moving
SPACE/DIRT/filter-link cases across 28 algorithms, with representative
44.1/48/96 kHz checks. Four wet outputs are exercised with Rear enabled;
callback allocation and release counts are zero. Space clock tests cover
nominal unity, fixed onset, non-integer frame counts and four-channel coherence.
The installed trial AU passed system validation. Original and XL converter
boundary checks retain their independent reference results at nominal/clean
settings. See `docs/CLOCK_EXPERIMENT.md` for evidence and limits.

Release CI builds both platforms from the tagged source, runs the public
clock-domain and empty-cache checks, and verifies executable architectures,
macOS signatures, archive contents and provenance before publication.
Private-ROM regression is local. These checks do not establish listening
acceptance, all-host multichannel acceptance, Intel runtime acceptance of the
new controls or Daisy realtime CPU margin. The XL engine remains a preview;
the intermittent Logic focus issue is not claimed fixed.
