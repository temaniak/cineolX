Cineol-X 224 **1.2 Alpha** for **Windows x64** and **macOS Universal**.
This is a GitHub **prerelease**, tag `v1.2Alpha`, numeric plugin/bundle version
**1.2.0**. Changes below are relative to 1.1a. Existing plugin identifiers,
parameter IDs/indices, presets and supported ROM/cache formats remain compatible.

### Fixes and control changes

- **Original 224 Plate pre-delay (#13):** both Plate programs now stop at the
  physical 107 ms limit. Moving old over-limit automation previously wrapped a
  delay-memory address and could produce howling feedback. Existing stored
  values are retained and resolve safely to 107 ms; no re-import is required.
- **XL Attack/Depth 99 (#16/#17/#19/#20):** the maximum now resolves to the
  valid physical endpoint, preserving the reverb instead of reaching an
  internal mute value. All 23 Attack/Depth controls across 19 reverbs are
  protected, including both sides of split programs. Old raw-255 sessions and
  automation remain readable and resolve to the corrected maximum.
- **Original 224 Mod Rate/Depth (#14):** the controls now retain independent
  settings. Changing Rate keeps Depth, and changing Depth keeps Rate, including
  host automation and immediate session/preset recall. This intentionally
  departs from the v4.4 panel's Depth reset on Rate edits. Native period/step
  mapping and 1-16 ranges remain; Rate 1 and 2 share the shortest interval at a
  fixed Depth. Program changes and Mod toggles retain their existing resets.
- **Rich Plate/Split Chorus (#15/#18):** rechecked throughout the real plugin
  parameter path. Its tail effect requires Mod plus Dynamic Decay and/or
  Optimization; the upper half retains the firmware's constant timing. No new
  delay-tap modulation or additional DSP correction is introduced by this recheck.
- Previous restored controls, HF endpoint and bypass-transition corrections
  remain included. Clean, Dark Hall Variation, SPACE, DIRT, optional Rear
  outputs and the existing full/compact interface are retained.

### Validation

The assembled code passed local all-28-program checks in Original/Clean at
44.1/48/96 kHz, including input-silent tails, block-size/offline invariance,
mono/four-output routing, Spillover, presets, sessions and callback allocation
checks. Focused regressions cover moving Plate pre-delay, maximum Attack/Depth,
all eight Rich switch combinations, all 16 by 16 modulation settings in both
orders, and the earlier smooth/latency-aligned bypass correction.

Actual universal AU/VST3 bundles passed 272 six-second signal renders on arm64
and x86_64 through Rosetta before the release-only version bump. Saved AU and
VST3 example WAVs match byte-for-byte within each architecture. Current-host CPU
checks passed; this does not establish Daisy or physical Intel realtime margin.
See [the assembled report](../FOUR_FIXES_VALIDATION_2026-11-09.md) for evidence.

Release CI builds Windows x64 VST3/Standalone and macOS Universal
AU/VST3/Standalone, checks isolated first-use/import safety and the Space clock,
and verifies the packaged binaries, checksums and macOS signatures. The complete
private-bank DSP suite remains local; private ROMs/banks are not uploaded to CI.

### Installation and limits

- **Windows x64:** replace the complete `.vst3` folder in
  `C:\Program Files\Common Files\VST3\`. Standalone is optional.
- **macOS 11 or later:** AUv2, VST3 and Standalone include Apple Silicon and
  Intel. Bundles are ad-hoc signed, not notarized; see `INSTALL.txt`.
- Restart/rescan your DAW after replacing the plugin. Keep a previous binary
  and session copies if exact historical renders are needed: the corrected
  invalid endpoints and formerly coupled automation intentionally change sound.
- Existing original-224 and corrected XL v5 caches are reused. Supply your own
  original 224 v4.4 and optional complete 224XL v8.21 ROM sets; no ROMs, prepared
  banks, firmware images or private recordings are included.
- Human listening acceptance, Cubase-specific bypass confirmation and complete
  Logic first-open/focus compatibility remain separate from automated checks.
  The Logic idle-paint workaround remains experimental.
- Linux binaries and CLAP are not included in this release.
