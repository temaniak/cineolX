Cineol-X 224 v0.9.6 for **macOS Universal** and **Windows x64**.

### Fixed rebuild: XL ROM import

The release archives have been replaced with a corrected **0.9.6 Fixed** build.
The plugin version remains 0.9.6; plugin identifiers, parameters, presets and
prepared-bank formats remain compatible.

- ROM setup stays visible when importing XL alongside an already loaded 224,
  including progress and failure messages. **Close** returns to a loaded engine.
- **Choose ROMs...** selects ROM files or ZIPs; **Choose folder...** selects a
  directory. Windows native dialogs no longer receive conflicting selection flags.
- Errors report the number of unique supported chips found and name known
  unsupported firmware versions, such as 224XL v8.1A.
- The XL formatter's 64 KiB scratch image is allocated outside the operator's
  fixed-size coroutine frames, avoiding a potential fatal frame-size overflow
  during firmware preparation.
- Invalid files, malformed ZIPs, repeated attempts and failed XL imports with an
  existing 224 cache are checked on both build platforms without private ROMs.
- Local full v8.21 preparation, import alongside 224 and cached restart passed.
  The prepared 22-program XL bank is byte-identical to the previous bank; this
  rebuild does not change the sound. The reported Windows Studio One crash has
  not been reproduced directly in that host.

Install the corrected archive over the earlier 0.9.6 build and restart your DAW.
If XL import previously failed, reopen ROM setup and import the complete v8.21
set. The original 224 cache is retained.

This release activates native 224XL dynamics and refines the editor. It includes
all features of v0.9.5: 28 algorithms, the shared preset bank, eight quick preset
keys, Spillover and Low latency.

### Changes since v0.9.5

- **Dynamic Decay/gating** now follows falling input levels and retriggers on
  new input in all 19 XL reverb algorithms. Short stop times produce gated tails.
- **LF STOP DECAY**, **MID STOP DECAY** and **REV STOP DLY** are active. The delay
  holds normal decay before switching to the stop settings.
- **Decay Optimization** adjusts feedback diffusion during XL decay. The existing
  **Decay Opt** button controls the selected original-224 or XL engine.
- Both switches and all stop settings belong to sound presets and DAW state.
  Plugin identifiers, parameter IDs/indices and preset format 4 are preserved.
- **Dyn Decay** occupies the former **Page n/n** header cell beside Mod Enh and
  Decay Opt. Text sizes, column alignment and spacing remain consistent. Numbered
  page buttons provide navigation without changing parameters or clearing tails.
- Quick preset keys no longer draw hover, focus or selection underlines. Their
  LEDs indicate the recalled preset.
- Updated README, first-use/upgrade instructions and actual editor screenshots.
- Public-source and package checks reject private XL banks as well as original
  banks and ROMs. Daisy retains the original-224 engine and processing behavior.

Chorus & Echo, Resonant Chords and Multiband Delay have no reverb dynamics in the
original XL firmware, so these switches remain unavailable for those effects.
Spillover retains the previous algorithm's tail on switching; Dynamic Decay
changes decay within the active algorithm. They are separate controls.

### Important: upgrading from v0.9.5

The new version-4 XL cache stores dynamics metadata and initial state. **Import
your complete original 224XL v8.21 ROM set once again after upgrading.** Click
the Model / 224 XL indicator to open ROM import. The previous version-3 XL cache
is preserved. Original 224 v4.4 caches and existing presets remain compatible.

### First launch: supply your own ROMs

ROMs and prepared banks are not included in either archive. Import locally using
**Choose ROMs...** for files/ZIPs or **Choose folder...** for a directory, then
wait for preparation before selecting an algorithm.

| Programs | Supported firmware | Complete set |
| --- | --- | --- |
| Six original 224 programs | **Lexicon 224 v4.4** | **ROM1-ROM5**, five 2,048-byte files |
| 22 desktop XL programs | **Lexicon 224XL v8.21** | Eleven chips: **SBC1-SBC3**, three 2,048-byte files; **NVS1-NVS8**, eight 4,096-byte files |

Both sets are needed for all 28 programs. Files are recognized by SHA-256 rather
than filename. Incomplete, modified and other firmware sets are rejected. Files
stay local; subsequent launches use the prepared cache. Before preparation,
audio passes dry and the unavailable engine's algorithms are disabled.

### Downloads and installation

- **macOS Universal:** AUv2, VST3 and Standalone for Apple Silicon and Intel,
  macOS 11 or later. Copy AU to `~/Library/Audio/Plug-Ins/Components/`, VST3 to
  `~/Library/Audio/Plug-Ins/VST3/`, and the standalone app to Applications.
  Bundles are ad-hoc signed; see `INSTALL.txt` for quarantine handling.
- **Windows x64:** VST3 and Standalone. Copy the entire `.vst3` folder to
  `C:\Program Files\Common Files\VST3\`. The standalone executable is optional.

Restart or rescan the DAW after installing. `SHA256SUMS.txt` covers both ZIPs;
each contains `INSTALL.txt`, README and source provenance in `BUILD-INFO.json`.

### Validation

Local private-ROM checks passed **27,117 exact slow/fast controller transitions**
across all 19 reverb algorithms and all four switch combinations. Native audio
renders verified dynamics behavior, finite output and no allocations/releases.
Full plugin regression passed all 28 algorithms, 618 active fader endpoints,
presets/session recall, numbered pages and block independence at 44.1/48/96 kHz.
Installed universal Audio Unit validation passed for the dynamics update.

Both platform builds run empty-cache first-use and invalid-ROM import checks and
verify their packaged binaries. macOS packaging verifies arm64/x86_64 architectures and signatures;
Windows packaging verifies x64 PE binaries. ROMs, banks and private fixtures
are never uploaded to CI. These checks do not establish exact physical hardware
timing or replace listening tests in the host.
