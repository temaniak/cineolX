Cineol-X 224 **1.3a** is a prerelease for **Windows x64** and **macOS Universal**.
The numeric plugin version is **1.3.0**. The desktop plugin now offers nine
original 224 programs and 22 optional 224 XL programs, for a total of 31.

### New original 224 programs

- **Room A (29)** is a modulated room reverb and the only new program with
  Decay Optimization.
- **Constant Density Plate A (30)** sums the left and right inputs before the
  plate network.
- **Chorus A (31)** uses the first four faders to set the levels of four
  chorus voice pairs. Each pair level can be automated.

Selecting any of these three programs in the **224** menu recalls its ROM
factory settings. Each works in Original and Clean. Automate its pre-delay
with **224 Additional Pre-delay**, which follows the selected program's range.
[GitHub issue #21](https://github.com/temaniak/cineolX/issues/21)

### Session and cache compatibility

- Use **224 Additional Program** to automate the new selections. Choose
  **Use Algorithm** to return to the existing **Algorithm** selector. The
  legacy **Algorithm** and VST3 **Program** parameters keep their 28 positions
  so existing DAW automation recalls the same programs.
- Cineol-X reads earlier `.cineol224` presets and saves presets in format v8
  to capture the new selection and controls.
- The v1 224 cache still opens the first six 224 programs. Importing the ROMs
  creates the v2 cache alongside it. Windows and macOS use the same v2
  layout, and the portable bank embedding tool accepts v2.

### Installation

- **Windows x64** includes VST3 and Standalone. Copy the entire VST3 bundle to
  `C:\Program Files\Common Files\VST3\`.
- **macOS 11 or later** includes Universal AUv2, VST3 and Standalone for
  Apple Silicon and Intel. Move older copies of the AU from the system or
  user Components folder to a backup outside both AU scan folders. Install
  the new AU in `/Library/Audio/Plug-Ins/Components/`.
- Restart or rescan your DAW. See `INSTALL.txt` in the archive for both
  platforms and use the attached `SHA256SUMS.txt` to verify downloads.

### Validation

Development AU and VST3 builds passed tests on Apple Silicon and through
Rosetta with all three new programs in Original and Clean. These checks
covered live control changes and tails after the input fell silent. Plugin
checks covered legacy session restore, presets and processing at 44.1, 48
and 96 kHz. Fixed-point DSP checks matched the Reflexion reference for the
tested settings across all nine original 224 programs.

Windows x64 CI checked first use with an empty cache, DSP clock behaviour and
16 graphics cases across interface sizes, themes and display scaling. macOS
Universal CI verified both binary architectures and bundle signatures.
