Cineol-X 224 **0.99B (alpha)** for **macOS Universal** and **Windows x64**.

### macOS plugin compatibility

AU and VST3 now export only their format entry points. This isolates internal
JUCE symbols from other plugins loaded into the same process and addresses the
assignment/cleanup collision investigated after a VST3 crash through Blue Cat
PatchWork AAX in Pro Tools. The controlled replay failed before the correction
and passed afterward on Apple Silicon and Intel via Rosetta, including mixed
old/new modules and both load orders. Acceptance in the affected customer's
Pro Tools/PatchWork session remains pending.

### Editor preferences and parameter help

- Display brightness, Option illumination, compact mode and editor width now
  persist as defaults across instances and application restarts. Explicit DAW
  session settings take precedence; older sessions inherit current defaults.
- LED cores receive a small warm brightness lift above 75% brightness.
- A question-mark button enables contextual hover help in full and compact
  layouts. Help follows the selected program and page, covers available faders,
  screen values, mode switches and Settings, and starts disabled on editor open.

### Sound and compatibility

The released desktop plugin has no DSP or sound-algorithm changes over 0.99A.
Plugin identifiers and parameter IDs remain stable. Existing presets,
original-224 caches and XL version-5 caches remain compatible. Re-import the
complete XL v8.21 ROM set only when upgrading from a pre-version-5 XL cache.
The XL engine remains a preview with musical listening reviews pending.

This source revision also includes Daisy I/O conversion work and a corrected
experimental floating-point Hall engine. The separate Float Hall A/B plugin and
Daisy firmware are not included in these desktop release archives.

Public version: **0.99B**. Numeric AU/VST3 and bundle version: **0.99.2**.

### Downloads and installation

- **macOS Universal:** AUv2, VST3 and Standalone for Apple Silicon and Intel,
  macOS 11 or later. Copy the AU to `~/Library/Audio/Plug-Ins/Components/`, the
  VST3 to `~/Library/Audio/Plug-Ins/VST3/`, and the app to Applications.
  Bundles are ad-hoc signed; see `INSTALL.txt` for installation details.
- **Windows x64:** VST3 and Standalone. Copy the complete `.vst3` folder to
  `C:\Program Files\Common Files\VST3\`. The standalone executable is optional.

Restart or rescan the host after installation. Archives include documentation,
installation instructions and build provenance. SHA-256 checksums accompany
the downloads. ROMs, prepared banks and private recordings are excluded.
Supply your own original 224 v4.4 ROM1-ROM5 for the six original programs and
the complete 224XL v8.21 eleven-chip set for the optional 22-program preview.

### Validation and limits

Existing local validation covers help across 28 programs, 121 pages and 957
active screen bindings, appearance/session restoration, separate-process
preference persistence and full/compact component snapshots. The macOS symbol
isolation checks cover AU/VST3 exports on both architectures, mixed-module
replays and empty-cache checks with zero audio callback allocations/releases.
Evidence is described in `docs/Parameter_Help_2026-10-11.md` and
`docs/Display_Controls_2026-10-11.md`; local symbol-isolation evidence is retained
under `build/validation/symbol-isolation-20261022/`.

Release CI builds both platforms, checks empty-cache first use and verifies
archives, provenance, macOS universal architectures/signatures and Windows x64
executable headers before publication. These checks do not establish listening
acceptance, physical hardware behavior, Daisy CPU margin or full DAW-host
acceptance. The intermittent Logic focus issue is not claimed fixed.
