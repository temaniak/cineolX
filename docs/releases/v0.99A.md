Cineol-X 224 **0.99A (alpha)** for **macOS Universal** and **Windows x64**.

### Display and compact editor

- **Display brightness** (15–100%) and **Option illumination** (0–100%) are now
  available in the gear's Settings panel. Algorithm selectors, screen options
  and the active numbered page have more visible illumination.
- **Compact display mode** hides the physical faders and quick preset keys,
  reducing the default editor from 984 x 744 to **984 x 252**. Its independently
  redrawn housing includes recessed glass, a complete molded border, intact
  screw heads and an unobstructed title. The gear remains accessible above
  its Settings overlay.
- Drag each available numeric screen value **up to increase / down to decrease**
  in either mode. Hold **Shift** for finer adjustment; double-click restores
  the same default as the corresponding fader. Keyboard control is available.
- Screen controls reuse existing host parameters, native ranges, snapping,
  XL chorus/diffusion scaling and program-dependent pre-delay limits. Host
  automation updates the screen, and drag gestures have matching begin/end
  events. Unavailable controls remain disabled.
- Brightness, illumination and compact mode are stored per instance in DAW
  sessions, independently of sound presets. The preset browser and ROM setup
  remain accessible in compact mode.

### Compatibility

This release changes presentation and control access; it introduces no audio
engine changes over v0.9.8. Plugin identity and parameter IDs/indices stay stable.
Existing sound presets and original-224 caches remain compatible. The XL preview
still requires the version-5 cache: re-import the complete 224XL v8.21 ROM set
only if upgrading from an older XL cache. Existing v5 users need no new import.

Public tags, archive names and build provenance use **0.99A**. AU/VST3 and macOS
bundle metadata use the monotonically increasing numeric version **0.99.1**.
The next requested public releases will use 0.99B, 0.99C, 0.99D and subsequent
letters. Version 1 requires an explicit request from the project owner.

### Downloads and installation

- **macOS Universal:** AUv2, VST3 and Standalone for Apple Silicon and Intel,
  macOS 11 or later. Copy the AU to `~/Library/Audio/Plug-Ins/Components/`, the
  VST3 to `~/Library/Audio/Plug-Ins/VST3/`, and the app to Applications.
  Bundles are ad-hoc signed; installation details are in `INSTALL.txt`.
- **Windows x64:** VST3 and Standalone. Copy the complete `.vst3` folder to
  `C:\Program Files\Common Files\VST3\`. The standalone executable is optional.

Restart or rescan your DAW after installing. Both archives include release
notes, README, installation instructions and `BUILD-INFO.json`; SHA-256 checksums
cover the downloads. ROMs, prepared banks and private recordings are excluded.
Supply your own original 224 v4.4 ROM1–ROM5 for the six original programs and
complete 224XL v8.21 eleven-chip set for the optional 22-program desktop preview.

### Validation and limits

The new display checks passed for all 28 available programs and their pages,
including per-session appearance restoration, compact/full layout, upward and
downward mouse drag, host updates, Dirt inversion, XL scaling and balanced
parameter gestures. Real component snapshots were reviewed for the housing,
Settings, reduced brightness and compact preset dialogs/browser.

The existing dual-bank plugin regression passed preset/session, mono/stereo,
Spillover and block-size tests at 44.1/48/96 kHz. The callback allocation/release
check reported zero. Release packaging checks universal macOS architectures and
signatures, Windows x64 executable headers, archive integrity and provenance.
Private-ROM regression was local; CI performs public empty-cache first-use checks.

XL retains its preview status and pending musical listening reviews from v0.9.8.
The intermittent Logic focus issue is not claimed fixed. These editor tests do
not establish physical hardware behavior, Daisy realtime margin or DAW-host
acceptance of the new release.
